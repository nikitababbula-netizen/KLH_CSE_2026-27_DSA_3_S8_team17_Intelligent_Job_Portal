Intelligent Job Portal

An algorithm-based job portal designed to improve job searching and
candidate-job matching using advanced Data Structures and Algorithms.

 Current Implementation

- KMP Pattern Matching
- Rabin-Karp Pattern Matching
- Z-Algorithm
- Edit Distance for Fuzzy Search
- Text Similarity

Technologies Used

- Java
- Git
- GitHub
- Maven
  
DSA Concepts

- String Algorithms
- Dynamic Programming
- Hashing
- Similarity Matching
- Priority Queue

Project Objective

To provide efficient job searching and intelligent candidate-job matching
using advanced algorithms.
